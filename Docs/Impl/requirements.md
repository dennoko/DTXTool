# DTXTool 要件定義書

## 1. 概要・目的

**DTXTool** は、アセット制作者向けの Unity エディター専用テクスチャリングツールです。
「対象箇所の指定（マスク作成／指定）→ 質感（色・テクスチャ・ノーマル）の設定 → リアルタイム確認 → 最終出力」という一連の作業を Unity 上で**最高効率かつ直観的**に完結させることを目的とします。

- **対応 Unity バージョン**:
  - **Unity 2022.3.22f1**（Built-in RP / lilToon でのプレビューを主な想定）
  - **Unity 6**（URP 等でも問題なく動作）
- **配置**: `Assets/dennokoworks/DTXTool/`（エディター専用、ビルドには一切含めない）

---

## 2. 対象オブジェクト・マテリアル管理

- **編集単位**: **1つの対象（1 Renderer / 1 Material）** に絞ったシンプルで集中できる構成とする。
- **マテリアル（質感）ベース設計**:
  - 1つのレイヤーで **Base（色 / テクスチャ）** と **Normal（ノーマルマップ）** をセットで管理する。
  - 最終出力は **BaseMap** と **NormalMap** の2枚（および編集データを含む **PSD**）とする。
- **シェーダープロパティ対応**:
  - プレビュー対象マテリアルのシェーダーから、BaseMap 用（`_MainTex` / `_BaseMap` 等）および NormalMap 用（`_BumpMap` 等）のプロパティを自動判別する。
  - 必要に応じてドロップダウンから手動で差し替え可能とする（lilToon / Standard / URP Lit 等にシームレス対応）。
- **プレビュー安全機構**:
  - プレビュー中は一時的な RenderTexture をマテリアルへ注入してリアルタイム表示する。
  - **Ctrl+S（アセット保存）・Play モード移行・スクリプト再コンパイル・ウィンドウ閉鎖時**には自動で元のテクスチャ参照へ復元する。
  - クラッシュ／強制終了時にも次回起動時に復旧データから自動復元できる安全機構を備える。

## 3. 目指す体験（コアワークフロー）

### Step 1: 対象個所の指定（マスク指定）

以下の2通りの方法で対象箇所を指定できる。

1. **シーン上 ／ 2D UVプレビュー上でのクリック選択**
   - `MaskMaker V4` の選択コア（`Dennoko.UVMaskMaker.Core` 相当）および 2D UV プレビュー UI を DTXTool 内に統合し、**外部パッケージへの依存なく DTXTool 単体で完結**して動作させる。
   - クリック選択（UVアイランド単位・ポリゴン/連結単位・対称ミラー・Shift追加 / Ctrl除外・ドラッグ/連続選択など）や 2D UV 上での選択をシームレスに利用可能にする。
2. **マスク画像の直接指定**
   - 外部で作成したマスク画像（`Texture2D`）をドラッグ＆ドロップで直接割り当て可能。
   - マスクの**反転**・**不透明度**・**ぼかし（フェザー）**調整に対応する。

#### レイヤー作成と再調整のフロー
- **新規レイヤー作成（基本フロー）**:
  1. シーン上または 2D UV プレビュー上で範囲選択を行い、選択を確定する。
  2. 確定した選択範囲をもとに新規レイヤーを作成する。
- **既存レイヤーの範囲再調整**:
  - 既存レイヤーを選択して「範囲の再調整」モードに入ると、シーン上をクリックして追加・除外・ミラー調整しながら、モデル上の見た目をリアルタイムに確認・更新できる。

### Step 2: 質感（色 or テクスチャ ＆ ノーマル）の設定

1つのレイヤー内でベースとノーマルを直観的に設定できる。

- **ベース設定**:
  - **単色（Color）** または **テクスチャ（＋Tintカラー乗算）** を切り替え可能。
- **ノーマル設定**:
  - **ノーマルマップ（Texture2D）** および **ノーマル強さ（Normal Scale）** を設定可能。
  - 単色レイヤー時のノーマルは「設定なし（透過）」または「平坦化」として扱えるようにする。
- **配置・タイリング・デカール**:
  - テクスチャおよびノーマルの **タイリング（X/Y）**・**オフセット（X/Y）**・**回転（Rotation）** に対応（ベースとノーマルのタイリング同期／個別設定も可能）。
  - UV 空間上の任意位置に1点貼り付けできる **デカール（Decal）モード** にも対応する。
- **ブレンド・不透明度**:
  - ブレンドモード：**通常（Normal） / 乗算（Multiply） / 加算（Additive） / スクリーン（Screen） / オーバーレイ（Overlay）**
  - レイヤー **不透明度（Opacity）**
  - NormalMap の合成は **RNM（Reoriented Normal Mapping）** ＋ ベクトル正規化により破綻なく合成する。
- **下地（ベースレイヤー）**:
  - 最下層に単色下地、または既存の **BaseMap / NormalMap テクスチャを下地として読み込む** 機能を備える。

### Step 3: 繰り返し ＆ UI/UX 体験

- レイヤーの追加・複製・削除・表示切替・順序変更（Undo/Redo 対応）を繰り返しながら、シーン上のモデルでリアルタイムに仕上がりを確認する。
- **UI 構成**:
  - **UI Toolkit（Dennoko テーマ / USS 準拠）** によるエディターウィンドウ。
  - **シーンビューオーバーレイ（MaskMaker V4 式の HUD / ラジアルメニュー）** を搭載し、視線移動を最小限に抑えて範囲選択・確定・モード切替を高速に行える体験を実現する。

### Step 4: 最終出力（PNG ベイク ＆ PSD ラウンドトリップ）

#### 1. PNG 出力（BaseMap / NormalMap）
- BaseMap と NormalMap の2枚を高品質にベイクして PNG 出力する（NormalMap は自動で `Texture Type = Normal map` としてインポート設定）。
- **UV シーム対策**: 出力時に UV 境界のにじみ・目立ちを防ぐ **自動パディング（エッジ拡張 / Dilation）** を適用する。

#### 2. PSD 出力 ＆ 再読み込み（続きの調整）
- **独自実装の PSD ライター / リーダー** により実装する。
- **外部ソフト互換性**: Photoshop / CLIP STUDIO PAINT / GIMP / Krita 等で問題なく開ける標準準拠の PSD（8bit RGB / RLE 圧縮等）として出力する。
- **PSD 内のフォルダ・レイヤー構造**:
  - 改変用としてユーザーに配布した際にも扱いやすい**綺麗なレイヤー名・フォルダ構造**を維持する。
  - **1つの PSD 内に `BaseMap` フォルダと `NormalMap`（初期非表示）フォルダを同梱**して出力する。
- **外部ファイル無しでの状態復元**:
  - `.json` 等の外部サイドカーファイルは持たず、**PSD ファイル単体**を読み込むことで前回の続きから調整を再開できる。
  - 綺麗なレイヤー名を維持しつつタイリング・テクスチャ参照・マスク選択情報などのツール固有パラメータを完全復元するため、PSD 内の不可視メタデータ用レイヤー（例: `_DTX_META` 等）または PSD メタデータ領域に復元情報を保持する設計をベースとする。
  - ※ **DTXTool 以外で作成された PSD は読み込み対象外**とし、判別不能な場合は明確なメッセージを表示して安全に中断する。

## 4. 非機能要件・技術方針

- **描画・合成処理**: RenderTexture ベース（シェーダー合成）による高速なリアルタイムプレビューと高解像度ベイク（例: 512 / 1024 / 2048 / 4096）。
- **カラースペース**: Linear / Gamma 両環境、特に Unity 2022.3 / Unity 6 の標準的な Linear 環境でガンマ空間ベースのブレンド演算（Photoshop 等と近似した結果）および正しい NormalMap エンコード・デコードを行う。
- **保守性**: Core ロジック（選択・合成・PSD I/O）と UI（UI Toolkit / Scene Overlay）を明確に分離し、単体テスト・スモークテストしやすい構成とする。
