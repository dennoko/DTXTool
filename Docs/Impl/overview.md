アセット制作者向けのUnityでのテクスチャリングツール

Unity2022.3.22f1ならびにUnity6に対応する。

目指す体験

1. 対象個所の指定
マスク画像 or シーン上をクリックして選択
シーン上で選択する場合の体験は基本的に dennokoworks の MaskMaker V4 を参考にする。

2. 色 or テクスチャ ＆ ノーマルを設定
テクスチャとノーマルはタイリングを設定可能

3. 全て終わるまで1,2を繰り返す

4. 最終的にベースマップとノーマルマップとして出力
PSD出力に対応し、出力したPSDを読み込んで次回以降続きの調整ができるようにする（このツール以外で作ったPSDは読み込み対象外）
